# GameZone — internal design preview

This branch contains an **unpublished prototype** of the GameZone front-end. The website is not complete and GitHub Pages is not enabled.

- Black/gold responsive UI with Yandex Games-inspired catalogue layout.
- Ten explicit sample cards, **not playable or licensed games**.
- Search, category filters and placeholders for friends, profile, rankings, messenger and admin dashboard.
- No Firebase or actual user accounts are connected.
- 100+ licensed HTML5 games, multiplayer integration and safety features still require implementation and the owner's individual approval.

Do not release publicly as the finished GameZone until all approved games and functionality are implemented and tested.
